# Security Policy

## Supported Versions

We actively maintain the latest version of the project.

| Version | Supported |
| ------- | --------- |
| `main`  | :white_check_mark: |
| Older versions | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately and responsibly.

### Preferred Method

Please use GitHub's **Private Vulnerability Reporting** feature:

**Repository → Security and quality → Advisories → Report a vulnerability**

Do not create a public GitHub issue for security vulnerabilities.

### Email

If GitHub Private Vulnerability Reporting is unavailable, you can report
security vulnerabilities directly to:

**kryvexoperations@gmail.com**

Please use the subject:

`[SECURITY] Vulnerability Report - KRYVEXCore Cricket`

### What to Include

Please include as much of the following information as possible:

- Description of the vulnerability
- Steps to reproduce the issue
- Affected files or components
- Affected versions
- Potential impact
- Proof of concept, if applicable
- Suggested mitigation or fix, if known

Please do not include passwords, API keys, access tokens, or other
unnecessary sensitive information in the report.

## Responsible Disclosure

Please give the maintainers reasonable time to investigate and address
the vulnerability before publicly disclosing it.

We appreciate responsible security research and will make a reasonable
effort to acknowledge valid reports.

## Security Updates

Security fixes will be released through the project's normal release
process.

When appropriate, security advisories will be published through GitHub's
Security Advisory system.
